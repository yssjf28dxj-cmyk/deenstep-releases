## Русский

DeenStep помогает постепенно приучаться к ходьбе и учиться небольшими шагами. Здесь опубликованы тестовые APK для Android.

**Версия 0.12.0 опубликована 30 октября 2026.** [Скачать APK для Android](https://github.com/yssjf28dxj-cmyk/deenstep-releases/releases/download/v0.12.0/DeenStep-Test-0.12.0.apk) · [Описание версии](https://github.com/yssjf28dxj-cmyk/deenstep-releases/releases/tag/v0.12.0).

### Как скачать и установить

1. Открой раздел Releases на Android-устройстве и выбери нужную версию.
2. В разделе Assets скачай файл `DeenStep-Test-0.12.0.apk`. Архивы «Source code» не являются приложением.
3. Открой скачанный APK. Если Android попросит, разреши установку из используемого браузера или приложения «Файлы».
4. Подтверди установку в системном окне Android.

Для загрузки публичного APK не нужны Google-аккаунт, GitHub-аккаунт или персональное приглашение.

**Если DeenStep уже установлен, устанавливай новую версию поверх прежней: в системном окне выбирай «Обновить». Не удаляй старую версию и не очищай её данные.** Это позволяет сохранить профиль и прогресс; перед обновлением можно дополнительно создать резервную копию в приложении. Если Android не предлагает обновление или сообщает о конфликте, сохрани сообщение и передай разработчику — не удаляй приложение для обхода ошибки.

### Совместимость и ограничения

- Android 7.0 и новее. Фактическая работа отдельных датчиков зависит от устройства.
- Это тестовая сборка: возможны ошибки.
- Проверка точности шагомера на реальном телефоне ещё не завершена.
- APK предназначен для Android. Версии для iPhone/iPad здесь нет.

## English

DeenStep helps you build a walking habit gradually and learn in small steps. This repository is for Android test APK downloads.

**Version 0.12.0 was published on October 30, 2026.** [Download the Android APK](https://github.com/yssjf28dxj-cmyk/deenstep-releases/releases/download/v0.12.0/DeenStep-Test-0.12.0.apk) · [Release notes](https://github.com/yssjf28dxj-cmyk/deenstep-releases/releases/tag/v0.12.0).

### Download and install

1. Open Releases on your Android device and select the version.
2. Under Assets, download `DeenStep-Test-0.12.0.apk`. “Source code” archives are not the app.
3. Open the downloaded APK. If Android asks, allow installation from the browser or Files app you are using.
4. Confirm installation in the Android system dialog.

Downloading a public APK does not require a Google account, a GitHub account, or a personal invitation.

**If DeenStep is already installed, install the new version over it and choose “Update” in the system dialog. Keep the existing app installed and retain its data.** This allows your profile and progress to remain; you can also create an in-app backup before updating. If Android does not offer an update or reports a conflict, send the exact message to the developer. Do not uninstall the app to bypass the error.

### Compatibility and limitations

- Android 7.0 or later. Sensor availability depends on the device.
- This is a test build and may contain bugs.
- Pedometer accuracy on a physical phone has not yet passed acceptance testing.
- This APK is for Android. There is no iPhone/iPad build here.
