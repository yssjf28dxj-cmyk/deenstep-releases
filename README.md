# DeenStep / ДинСтеп — Android test builds

## Русский

DeenStep помогает постепенно приучаться к ходьбе и учиться небольшими шагами. Здесь доступны тестовые APK для Android.

**Тестовая версия 0.17.0.** [Скачать APK для Android](https://github.com/yssjf28dxj-cmyk/deenstep-releases/releases/download/v0.17.0/DeenStep-Test-0.17.0.apk) · [Описание версии](https://github.com/yssjf28dxj-cmyk/deenstep-releases/releases/tag/v0.17.0).

### Что изменилось в 0.17.0

- **Необязательное обновление:** можно установить, когда удобно. После установки важные и обычные обновления показываются по-разному.
- **12 новых русскоязычных роликов о пользе ходьбы** с контекстом исследований и ссылками на первоисточники. Один предлагается после завершённой прогулки в день; все доступны в «Настройки → Видео».
- **Стеклянные рамки** плеера и открывающихся окон, плавное раскрытие видео внутри текущего экрана.
- Обновление 0.16.2 → 0.17.0 на тестовом эмуляторе сохранило девять документов профиля и прогресса. Полная проверка роликов на настоящих телефонах ещё открыта.

Общие истории с ручной проверкой, вступление, выбор содержания и уведомления об обновлении сохранены.

Обратная связь и добровольная статистика из 0.14.0 сохранены. Статистика выключена по умолчанию; после согласия передаются технический ID, версия, активное время и посещения пяти разделов. Имя, здоровье, религиозные настройки, координаты и тексты экранов не передаются. Отключение останавливает отправку и удаляет неотправленную очередь; ранее переданные записи остаются.

Управление своими историями в этой тестовой версии связано с текущей установкой приложения. Обновляй поверх существующей версии, сохраняя её данные.

В настройках также доступны локальный технический отчёт TXT и кнопка «Проверить вибрацию». Технические отчёты автоматически не отправляются. Проверка вибрации не меняет прогулку.

### Как скачать и установить

1. Открой раздел [Releases](https://github.com/yssjf28dxj-cmyk/deenstep-releases/releases) на Android-устройстве и выбери версию.
2. В разделе Assets скачай `DeenStep-Test-0.17.0.apk`. Архивы «Source code» не являются приложением.
3. Открой скачанный APK. Если Android попросит, разреши установку из используемого браузера или приложения «Файлы».
4. Подтверди установку в системном окне Android.

Для скачивания публичного APK не нужны аккаунты Google/GitHub или персональное приглашение.

**Если DeenStep уже установлен, устанавливай новую версию поверх прежней и выбирай «Обновить». Не удаляй приложение и не очищай его данные.** Перед обновлением можно дополнительно создать резервную копию в приложении. Если Android не предлагает обновление или сообщает о конфликте, сохрани точное сообщение и передай разработчику.

### Совместимость и ограничения

- Android 7.0 и новее. Датчики и вибрация зависят от устройства.
- Это тестовая сборка: возможны ошибки.
- Приёмочные проверки точности шагомера и ощущения вибрации на физических телефонах отложены.
- Этот APK предназначен для Android. Версии для iPhone/iPad пока нет.

## English

DeenStep helps you build a walking habit gradually and learn in small steps. This repository provides Android test APK downloads.

**Test version 0.17.0.** [Download the Android APK](https://github.com/yssjf28dxj-cmyk/deenstep-releases/releases/download/v0.17.0/DeenStep-Test-0.17.0.apk) · [Release notes](https://github.com/yssjf28dxj-cmyk/deenstep-releases/releases/tag/v0.17.0).

### What changed in 0.17.0

- **Optional update:** install whenever convenient. After installing, important and optional updates have different notices.
- **12 new Russian walking-health videos** with research context and primary sources. One is suggested after a completed walk per day; all are available in Settings → Videos.
- **Glass-style frames** for the inline player and dialogs, with smooth expansion on the current screen.
- An emulator upgrade from 0.16.2 to 0.17.0 preserved all nine profile and progress documents. Full physical-device video acceptance remains open.

Shared stories with manual review, programme introduction, content choices and update notices remain available.

Feedback and optional usage statistics from 0.14.0 remain available. Statistics are off by default. With consent, they share a technical ID, version, active time and visits to five sections, without names, health data, religious preferences, coordinates or screen text. Turning them off stops sending and clears the unsent queue; it does not remove data already sent.

In this test version, control of your own stories is tied to the current app installation. Install updates over the existing app and retain its data.

Settings also include a local technical TXT report and a Test vibration button. Technical reports are not sent automatically. The vibration test does not change your walk.

### Download and install

1. Open [Releases](https://github.com/yssjf28dxj-cmyk/deenstep-releases/releases) on your Android device and choose the version.
2. Under Assets, download `DeenStep-Test-0.17.0.apk`. “Source code” archives are not the app.
3. Open the downloaded APK. If Android asks, allow installation from the browser or Files app you are using.
4. Confirm installation in the Android system dialog.

Downloading the public APK does not require a Google account, a GitHub account or a personal invitation.

**If DeenStep is already installed, install the new version over it and choose Update. Keep the existing app installed and retain its data.** You can create an in-app backup before updating. If Android does not offer an update or reports a conflict, send the exact message to the developer.

### Compatibility and limitations

- Android 7.0 or later. Sensor and vibration behavior depends on the device.
- This is a test build and may contain bugs.
- Physical-phone acceptance checks for pedometer accuracy and felt vibration are deferred.
- This APK is for Android. An iPhone/iPad version is not available yet.
